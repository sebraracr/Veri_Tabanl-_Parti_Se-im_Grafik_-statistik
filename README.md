# 🌸Seçim Sonuçları Takip Uygulaması

Bu proje, **C# Windows Forms** ve **SQL Server** ile geliştirilmiş bir masaüstü uygulamasıdır. 
İlçelere göre beş partinin oy sayıları girilir ve veritabanına kaydedilir. 
Grafik ekranında partilerin toplam oyları sütun grafiğiyle, seçilen ilçenin oy sonuçları ise çubuklar ve sayısal değerlerle gösterilir.
